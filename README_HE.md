# TP-Link Battery Alert

אפליקציית Android לניטור סוללת נתב נייד ולהצגת התראה כשהסוללה מגיעה ל־10% ומטה.

## הורדה

[הורדת APK ישירה – תמיד הגרסה האחרונה](https://github.com/HAKOL-MILEMALA/TPLink-Battery-Alert/releases/latest/download/M7200-Car-Alert.apk)

[כל הגרסאות והיסטוריית השינויים](https://github.com/HAKOL-MILEMALA/TPLink-Battery-Alert/releases)

## מה האפליקציה עושה?

- מתחברת לרשת ה־Wi-Fi של הנתב וקוראת את מצב הסוללה מממשק הניהול המקומי.
- מציגה במסך הראשי את אחוז הסוללה האחרון שהתקבל, יחד עם מועד העדכון.
- מבצעת בדיקת חיבור מיידית בעת הפעלת הניטור ובכל כניסה מחדש לאפליקציה.
- ממשיכה לבדוק את מצב הסוללה בערך פעם בדקה בזמן שהניטור פעיל.
- מנסה לחדש את הניטור לאחר אתחול Android ולאחר התעוררות המסך משינה.
- מציגה התראה כשהסוללה ב־10% ומטה ואינה בטעינה, וחוזרת עליה כל 3 דקות.
- מפסיקה את ההתראה ומאפסת את התזכורות כשהסוללה מגיעה ל־15% ומעלה או כשהנתב בטעינה.

האפליקציה מבצעת קריאה מקומית בלבד ואינה משנה הגדרות בנתב. אין שליחת נתוני סוללה לשרת, אין מערכת דיווחי תאימות ואין צורך בחשבון GitHub כדי להשתמש בה.

## התקנה והפעלה

1. התקן את קובץ ה־APK.
2. התחבר במולטימדיה או בטלפון לרשת ה־Wi-Fi של הנתב.
3. פתח את האפליקציה והזן את **סיסמת הניהול של הנתב** — לא בהכרח את סיסמת ה־Wi-Fi.
4. לחץ על **שמור והפעל ניטור**.
5. אשר את הרשאת ההתראות של Android.
6. אשר את בקשת Android לאפשר לאפליקציה לפעול ללא אופטימיזציית סוללה.

לאחר הבדיקה הראשונית תופיע הודעה אם החיבור הצליח או נכשל. במקרה של הצלחה, אחוז הסוללה יוצג במסך הראשי. אם הבדיקה נכשלת, האפליקציה תשמור את הקריאה האחרונה ותציג בבירור שהיא אינה עדכנית.

## הפעלה אוטומטית במולטימדיה

האפליקציה מבקשת להתעלם מאופטימיזציית הסוללה של Android, מפעילה מחדש את שירות הניטור לאחר אתחול ומבקשת בדיקה חדשה כאשר המסך מתעורר (SCREEN_ON / USER_PRESENT).

בחלק מהמולטימדיות קיימת בנוסף הגבלת רקע של היצרן. במקרה כזה יש לאפשר ידנית בהגדרות המולטימדיה:
- Autostart / הפעלה אוטומטית.
- פעילות ברקע ללא הגבלה.
- הפעלה אוטומטית לאחר אתחול, אם קיימת אפשרות כזו.

אין באנדרואיד הרשאה או מסך הגדרות אחידים ל־Autostart של כל היצרנים. לכן לא ניתן להבטיח שהיצרן לא יהרוג את השירות בזמן שינה; מומלץ לבדוק בפועל את ההתנהגות במולטימדיה.

## התראות

ערוץ התראת הסוללה מוגדר בעדיפות גבוהה, עם צליל ורטט. כשהסוללה ב־10% ומטה ואינה בטעינה, תוצג התראה ראשונה ולאחר מכן תזכורת כל 3 דקות. ההתראה נשארת במגירת ההתראות עד שהמשתמש מסיר אותה או עד שהמצב מתאפס.

משך ההופעה של חלונית ההתראה הקופצת נקבע על ידי Android והמולטימדיה ואינו ניתן להארכה מתוך האפליקציה. תזכורות חוזרות נועדו לצמצם את הסיכוי לפספס אותה.

## הערות תאימות

האפליקציה מנסה לבצע קריאת סוללה באמצעות פרוטוקול ממשק הניהול המקומי שהיא מכירה. אין במאגר רשימת דגמים שמובטח כי הם נתמכים. הבדיקה בתוך האפליקציה היא הקובעת: הצלחה פירושה שנתוני הסוללה התקבלו בפועל; כישלון יוצג למשתמש עם הסיבה שניתן לזהות.
