**[⬇️ הורדת האפליקציה (APK)](https://github.com/HAKOL-MILEMALA/M7200CarAlert/releases/latest/download/M7200-Car-Alert.apk)**

זהו קישור הפצה קבוע. שם קובץ ה-APK נשמר בכוונה לצורך תאימות לקישור הישן, אך האפליקציה עצמה כבר מיועדת לנתבי TP-Link MiFi ולא רק ל-M7200.

[לכל הגרסאות והיסטוריית העדכונים ב-GitHub](https://github.com/HAKOL-MILEMALA/M7200CarAlert/releases)

## גרסת דפדפן – ניטור M7200 באמצעות Tampermonkey

**[התקנת Tampermonkey ל-Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)** · **[התקנת סקריפט M7200 בלחיצה אחת](https://raw.githubusercontent.com/HAKOL-MILEMALA/M7200CarAlert/main/M7200-Battery-Alert.user.js)**

בנוסף לאפליקציית Android, אפשר לנטר את סוללת M7200 ישירות מהמחשב באמצעות סקריפט דפדפן. גרסת הדפדפן מיועדת כרגע ל-M7200 בלבד; היא אינה מעידה על תמיכה בכל דגמי TP-Link MiFi.

### מה הסקריפט עושה
- התראה רגילה ב-15% ומטה והתראה דחופה ב-10% ומטה.
- הערכת זמן עד לסף ביטחון של 5%, רק כאשר נאספו מספיק דגימות.
- חלונית קצרה בדפדפן והתראת Windows.
- נודניק ידני או אוטומטי אחרי 30 שניות; התזכורת חוזרת אחרי 3 דקות, או מוקדם יותר אם הסוללה יורדת בעוד 2 נקודות אחוז.
- בדיקות כל 3 דקות בשגרה וכל דקה כשהסוללה חלשה.

### התקנה
1. התקן את [Tampermonkey ל-Chrome](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo).
2. פתח את [קישור ההתקנה הישיר של הסקריפט](https://raw.githubusercontent.com/HAKOL-MILEMALA/M7200CarAlert/main/M7200-Battery-Alert.user.js).
3. בחלון Tampermonkey לחץ על Install / התקן.
4. חבר את המחשב לרשת ה-Wi-Fi של ה-M7200 והשאר ב-Chrome לפחות לשונית HTTPS אחת פתוחה, למשל Gmail.
5. אם תתבקש, פתח את דף הנתב והזן את סיסמת הניהול.

### דרישות והערות
- המחשב חייב להיות מחובר ל-Wi-Fi של ה-M7200; הסקריפט פונה לנתב בכתובת המקומית `192.168.0.1`.
- יש להשאיר את Chrome פתוח ולפחות לשונית HTTPS אחת פתוחה. לשונית הנתב עצמה היא HTTP ומשמשת להזנת הסיסמה; היא אינה מבצעת את ניטור הסוללה.
- הניטור המקומי אינו דורש אינטרנט לאחר ההתקנה. התקנה ראשונית ועדכונים מ-GitHub דורשים אינטרנט.
- סיסמת הנתב נשמרת באחסון Tampermonkey. הסקריפט אינו מצפין אותה בעצמו ואינו שולח אותה לשירות חיצוני.
- אין צורך להשאיר את לשונית הנתב פתוחה כל הזמן.

### עדכונים אוטומטיים
הסקריפט כולל `@updateURL` ו-`@downloadURL` שמצביעים לקובץ הרשמי במאגר. Tampermonkey בודק עדכונים בהתאם להגדרות העדכון שלו. אם מותקנת אצלך גרסה 1.4.2, התקן פעם אחת דרך הקישור שלמעלה כדי לעבור לגרסה 1.4.3 שמכילה את פרטי העדכון האוטומטי; מהגרסה הזאת העדכונים ייבדקו דרך Tampermonkey.

## מה האפליקציה עושה

- מנטרת את סוללת נתבי TP-Link MiFi דרך רשת ה-Wi-Fi המקומית.
- קוראת את מצב הסוללה פעם בדקה.
- מציגה התראת Android בולטת כאשר הסוללה מגיעה ל-10% ומטה, כל עוד היא אינה בטעינה.
- ההתראה נשלחת פעם אחת בכל מחזור פריקה, ומתאפשרת מחדש רק כשהסוללה עולה ל-15% ומעלה.
- שירות הניטור ממשיך לפעול ברקע ומופעל מחדש לאחר אתחול המולטימדיה, לאחר שהופעל פעם אחת ידנית.
- מזהה אוטומטית את שער ברירת המחדל של רשת ה-Wi-Fi, במקום להניח תמיד שכתובת הנתב היא 192.168.0.1.
- סיסמת הנתב נשמרת מוצפנת באמצעות Android Keystore (AES-GCM).
- מסך האפליקציה מאפשר לבדוק דגם, גרסת חומרה וגרסת קושחה, ולוודא בפועל שקריאת נתוני הסוללה עובדת.
- בדיקת העדכונים האוטומטית מתבצעת לכל היותר פעם בשבוע; אפשר לבדוק ידנית בכל רגע.
- אם נמצאה גרסה חדשה, האפליקציה מורידה APK מה-Release הרשמי, בודקת SHA-256 כאשר GitHub מספק אותו, ומעבירה את ההתקנה למתקין Android. המשתמש עדיין מאשר את ההתקנה במערכת.

## בדיקת תאימות

לחץ על **בדוק דגם, גרסה ותאימות** לאחר חיבור המולטימדיה ל-Wi-Fi של הנתב והזנת סיסמת הניהול.

הבדיקה מתחברת לנתב בקריאה בלבד. היא אינה משנה הגדרות ואינה מבצעת אתחול או עדכון קושחה.

- **נתמך:** ההתחברות הצליחה והאפליקציה קראה בפועל אחוז סוללה תקין.
- **לא תואם לפרוטוקול הנוכחי:** הנתב הגיב, אך ממשק ההתחברות או מבנה נתוני הסוללה שונים.
- **לא ניתן לקבוע:** אין חיבור Wi-Fi, הסיסמה נדחתה או אירעה שגיאת תקשורת. שגיאה כזאת אינה הוכחה שהדגם אינו נתמך.

האפליקציה מציגה את הדגם והקושחה כפי שהנתב מדווח עליהם. בחלק מהדגמים גרסת החומרה אינה זמינה דרך הממשק; במקרה כזה היא תוצג כ"לא דווחה".

### שליחת דוח תאימות ל-GitHub

לאחר בדיקה מוצלחת או זיהוי של אי-התאמה אפשר ללחוץ על **שלח דוח תאימות ל-GitHub**. האפליקציה תפתח טיוטת Issue עם דגם הנתב, גרסאות התוכנה, תוצאת הבדיקה וגרסת האפליקציה.

הדיווח אינו נשלח אוטומטית: צריך להיות מחובר ל-GitHub ולאשר את שליחת ה-Issue. הדוח אינו כולל סיסמה, כתובת IP מקומית, שם רשת Wi-Fi, כתובת MAC או IMEI.

דוחות ייבדקו לפני שינוי [רשימת הנתבים הנתמכים](SUPPORTED_ROUTERS.md). אין הוספה אוטומטית של דגם לרשימת הנתמכים על סמך דיווח יחיד.

## דגמים וסטטוס תמיכה

רשימת הראיות והסטטוסים נמצאת בקובץ [SUPPORTED_ROUTERS.md](SUPPORTED_ROUTERS.md). חשוב להבחין בין דגם שמשתמש ככל הנראה באותו API לבין דגם שבו בדיקת התאימות של האפליקציה הצליחה בפועל.

ממשק tpMiFi הרשמי של TP-Link תומך במספר דגמי MiFi נוספים, אך התמיכה של האפליקציה הרשמית אינה מבטיחה תאימות לפרוטוקול שבו משתמשת האפליקציה הזאת.

## דרישות והנחות

- Android 8 ומעלה (מינימום API 26); פותח ונבדק מבנית עבור מולטימדיה עם Android 12.
- המולטימדיה חייבת להיות מחוברת לרשת ה-Wi-Fi של נתב ה-MiFi.
- נדרשת סיסמת הניהול של הנתב, לא סיסמת ה-Wi-Fi (אלא אם הן זהות).
- קריאת הסוללה המקומית אינה דורשת אינטרנט. בדיקת עדכונים ודיווח ל-GitHub דורשים אינטרנט.
- האפליקציה משתמשת כרגע בפרוטוקול JSON המקומי של TP-Link בנתיבים `/cgi-bin/auth_cgi` ו-`/cgi-bin/web_cgi`. דגמים עם פרוטוקול שונה לא יסומנו כתואמים רק מפני שהם מתוצרת TP-Link.

## הפעלה ראשונית

1. התקן את ה-APK מהקישור בראש המסמך.
2. חבר את המולטימדיה ל-Wi-Fi של נתב ה-TP-Link MiFi.
3. פתח את האפליקציה והזן את סיסמת הניהול.
4. לחץ על **בדוק דגם, גרסה ותאימות** ובדוק שמופיעה תוצאה חיובית ונתוני סוללה.
5. לחץ על **שמור והפעל ניטור**.
6. ודא שהתראת הפעילות השקטה מופיעה בשורת ההתראות.
7. אפשר לאפליקציה להציג התראות קופצות (Heads-up / Pop on screen).

אם במולטימדיה קיימת הגדרת Autostart או ניהול אגרסיבי של סוללה, יש לאפשר לאפליקציה הפעלה אוטומטית ולהחריג אותה ממגבלות חיסכון בסוללה.

## עדכוני APK וחתימה קבועה

כל גרסה חייבת להיחתם באותו מפתח פרטי כדי ש-Android יאפשר עדכון מעל האפליקציה הקיימת. המפתח נשמר ב-GitHub Actions Secret ואינו נמצא במאגר הציבורי.

בעת הכנת גרסה חדשה יש להגדיל גם את `versionCode` וגם את `versionName` בקובץ `app/build.gradle`. לאחר Push רלוונטי GitHub Actions יבנה APK מסוג Release חתום ויפרסם קובץ APK יחיד בשם `M7200-Car-Alert.apk`. שם הקובץ נשמר כדי שקישור ההורדה הקבוע לא ישתנה; שם האפליקציה והכותרת ב-Release הם כלליים.

## הערות Android

- Android יציג את מתקין החבילות ויבקש אישור משתמש לעדכון. אין התקנה שקטה.
- התקנת עדכון עשויה לדרוש לאפשר לאפליקציה **Install unknown apps / התקנה ממקור זה**.
- יצרני מולטימדיה עשויים להגביל שירותי רקע; יש לאפשר Autostart/Background activity ולהחריג את האפליקציה ממגבלות סוללה, אם האפשרויות קיימות.
- סוג השירות נשאר `dataSync` ו-`targetSdk 32`, כדי לא לשנות ללא צורך את התנהגות הניטור במולטימדיה הקיימת.
