# TP-Link Battery Alert – Community compatibility reports

This page is automatically regenerated by GitHub Actions from structured reports submitted through the Android app.

**These are community observations, not laboratory certification.** The status is specific to the exact reported model, hardware revision and firmware version. Android notification delivery is tracked separately and does not alter router protocol compatibility.

## Status rules

| Status | Meaning |
| --- | --- |
| Likely supported | One distinct GitHub account successfully read a valid battery percentage |
| Supported | Two or more distinct GitHub accounts reported successful battery reads |
| Likely unsupported | One distinct GitHub account confirmed the prerequisites and reported a protocol mismatch |
| Unsupported | Two or more distinct GitHub accounts confirmed the prerequisites and reported the same protocol mismatch |
| Disputed | At least one positive and one negative report, or one account reported both outcomes |

A second report from the same GitHub account never increases the count. Conflicting reports are not resolved by majority. Reports with incorrect passwords, network failures or unconfirmed prerequisites are not counted as negative evidence.

Battery notification results (received / threshold not reached / did not arrive) are shown separately. A notification failure does **not** mean the router protocol is unsupported.
